# INVI — pre-launch site

Cryptic waitlist + vote experience for INVI (UK teen body-care brand).
Single self-contained `index.html`. No build step, no dependencies.

- **Step 01** — join (first name, email, optional age, consent required)
- **Step 02** — vote for one of the three moments (ORIGIN / RISE / AFTER DARK), confirm, locked

Demo mode: no data leaves the page. The submit handler logs the payload it would
POST to a Google Apps Script endpoint.
